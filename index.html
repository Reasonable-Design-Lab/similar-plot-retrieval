How matching works

All results are Business 1 plots. The first view accepts either similar plot dimensions or similar allowable GFA. A plot can therefore look different but still offer similar development capacity.

Dimensions use width and aspect ratio rather than an exact outline-to-outline comparison. The next views add neighbouring land uses and road frontage.
